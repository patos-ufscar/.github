# Quack! 👋

Bem vindo ao PATOS, o melhor <strike>e único</strike> grupo de opensource da UFSCar

## Pretty Awesome To Open Source
PATOS é um grupo de estudos, aberto e sem hierarquia definida, focado em incentivar a cultura do free and open-source software (FOSS) dentro da comunidade UFSCar e principalmente entre os alunos de computação, através de aulas, eventos e outras atividades.
O grupo tem como principal objetivo despertar o interesse de outros alunos no campo do open-source. Para isso, o grupo funciona como um meio de conectar pessoas com interesses próximos dentro da área de computação, criando um ambiente convidativo e favorável onde os membros possam aprender e desenvolver habilidades técnicas e sociais, como práticas de programação, lideranças de projeto e desenvolvimento colaborativo. 

## Objetivos gerais
Ferramentas e conceitos que o grupo visa praticar:
- Boas práticas de desenvolvimento colaborativo;
- Talks sobre diferentes temas relacionados a computação;
- Documentação de projeto e/ou código;
- Git, GitHub/GitLab, Git Flow;
- Colaborações para projetos open-source;
- Liderança e trabalho em equipe;
- Portifólio de projetos;
- Go <3
